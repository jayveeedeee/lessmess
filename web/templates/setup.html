    Bootstrap this repository

    Creates the workflow files. Everything is merge-safe — existing content is never clobbered:

    • AGENTS.md — the workflow pointer and agent docs

    • .gitignore — keeps .lessmess/ personal except the workflow state
    • opencode.json — starter agent permissions
